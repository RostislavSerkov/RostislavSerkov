## Проекты

---

### 🖥 Linux Monitoring v1.0
Набор Bash-скриптов для исследования Linux-системы с цветным выводом, экспортом отчётов и анализом файловой системы.

**Стек:** Bash · Linux · awk · find · du  
**Фичи:** сбор системной информации, цветной вывод через CLI-параметры и config-файл, анализ директорий, MD5-хэши исполняемых файлов  
[→ Открыть репозиторий](https://github.com/RostislavSerkov/linux-monitoring-v1)

---

### 🗄 SQL Projects (B1–B6)
Серия учебных SQL-проектов: от базового SELECT до рекурсивных CTE и задачи коммивояжёра.

**Стек:** PostgreSQL · SQL  
**Покрытые темы:** SELECT / JOIN / агрегации · оконные функции · DML · Views · рекурсивные CTE · граф-обход  
[→ Открыть репозиторий](https://github.com/RostislavSerkov/-sql-projects)

---

### 🌐 Linux Networking
Конфигурация сети Linux: статические IP, маршрутизация, firewall (iptables/nftables), SSH-туннели.

**Стек:** Linux · iproute2 · iptables · nftables · SSH
